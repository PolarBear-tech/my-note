## Note

这是我大学学习的笔记知识库。

### 各个文件夹的作用

- `文本笔记` 文件夹是 以 `.md` 形式存储的文本笔记
- `组织`文件夹里的 `.canvas` 文件是用来组织所有的文本笔记和手写笔记体积太大了，以及其他的白板文件
- `模板` 文件夹里是各种模板，用于快速插入内容的
- `Marimo` 文件夹里是我所有的 `marimo`notebook
- `Clippings`文件夹是我搜集的网上知识，由 `Obsidian Web Clipper` 生成
- `我的计划.md` 文件是我所有正在进行的项目

#### 为什么我的 `手写笔记` 消失了

这是由于我现在使用了一种更加高效的记笔记方法，利用平板记笔记，形成 pdf 版本，但是 github 上传输大文件很麻烦，所以我放弃了在这里写我的手写笔记，但是在不久的将来我会找到新的地方安置我的手写笔记的。

### 插件说明

 - `Dictionary`：查单词的
 - `Git`：多设备同步
 - `Linter`：格式化
 - `marimo Bridge`：实现在 Obsidian 中打开 marimo 笔记
 - `Latex Suit`：写数学公式用的，虽然我很少打开它
 - `floating toc`：侧边的目录
